Tabular Dyna-Q

Initialize \(Q(s,a)\) and \(\mathit{Model}(s,a)\) for all \(s \in \mathcal{S}\) and \(a \in \mathcal{A}(s)\)
Loop forever:

  1. \(S \leftarrow\) current (nonterminal) state
  2. \(A \leftarrow \varepsilon\text{-greedy}(S, Q)\)
  3. Take action \(A\); observe resultant reward, \(R\), and state, \(S'\)
  4. \(Q(S,A) \leftarrow Q(S,A) + \alpha\left[R + \gamma \max_a Q(S',a) - Q(S,A)\right]\)
  5. \(\mathit{Model}(S,A) \leftarrow R, S'\) (assuming deterministic environment)
  6. Loop repeat \(n\) times:
    \(S \leftarrow\) random previously observed state
    \(A \leftarrow\) random action previously taken in \(S\)
    \(R, S' \leftarrow \mathit{Model}(S,A)\)
    \(Q(S,A) \leftarrow Q(S,A) + \alpha\left[R + \gamma \max_a Q(S',a) - Q(S,A)\right]\)

How might the tabular Dyna-Q algorithm above be modified to handle stochastic environments? How might this modification perform poorly on changing environments? How could the algorithm be modified to handle stochastic environments and changing environments?
