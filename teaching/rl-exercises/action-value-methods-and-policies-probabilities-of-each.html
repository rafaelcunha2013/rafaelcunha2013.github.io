Recall that for action-value methods, you must first select the method you will use to update the action-value function and then apply the selected policy using the estimation of the action-value function obtained.

Fill in Table 3 with the probability of selecting each action at time \(t=9\), rounded to three decimal places, using the methods listed below. Provide the equations that you used. If you decide to write Python code to answer this question, please attach it to your answer.
