Show that for a random variable \(X\) with a pdf \(f(x)\), \(\mathbb{P}(X=x)=0\) for all \(x\). To get a probability from a pdf, use \[\begin{align*} \mathbb{P}(a \leq X \leq b)=\int_a^b f(x) dx. \end{align*}\]

Hint: \(\mathbb{P}(X=x) = \mathbb{P}(x \leq X \leq x)\).
