Reinforcement Learning Tutorials

Seven hands-on tutorials, from multi-armed bandits to policy gradients. The code runs in your browser.

These tutorials accompany an introductory course on reinforcement learning. Each one alternates short explanations, coding tasks with hints, and experiments followed by questions about what the results show. You implement the methods yourself, then test where they work and where they fail. The lecture slides introduce the methods. The course map lists every concept with its slides and the tutorial tasks that practise it.

How the pages work

Tutorials 1–5 run Python in your browser: no installation and no account. Run the cells in order. Your edits are kept in your browser, and Download .ipynb saves your work as a Jupyter notebook, which you can also run on your own computer. Tutorials 6–7 use PyTorch, which does not run in the browser: they run on a free mybinder.org server that the page starts for you.

Reference text

R. S. Sutton and A. G. Barto, Reinforcement Learning: An Introduction, 2nd ed., MIT Press, 2018, free online from the authors. Each tutorial lists the chapters it builds on.

Running the notebooks on your own computer

Every tutorial page has a Download .ipynb button. To run the downloaded notebooks in Jupyter on your own computer:

  1. Install uv, a Python package and project manager (one command on macOS, Linux and Windows).
  2. Save pyproject.toml in a new folder, and put the downloaded notebooks in the same folder.
  3. Open a terminal in that folder and run:
uv run jupyter lab

The first run installs a suitable Python if needed, creates the environment (a .venv folder) with the packages at the versions the tutorials were tested with, and opens Jupyter. It downloads about 1 GB, most of it PyTorch for Tutorials 6–7, and takes a few minutes; later runs start in seconds. PyTorch 2.8 has no build for Macs with an Intel processor: on those, run Tutorials 6–7 on their pages.
